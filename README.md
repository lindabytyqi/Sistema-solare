# Sistema-solare - Swift Playgrounds:
Questo progetto è un’applicazione educativa sviluppata con Swift Playgrounds su iPad.
L’app permette di esplorare il Sistema Solare e di visualizzare contenuti astronomici dinamici, inclusi dati e immagini ottenuti tramite API.

Requisiti per far funzionare il progetto:
 - Essere connesso ad Internet
 - Scaricare tutta la cartella 5_Applicativo presente in GitHub
 - Avere un dispositivo Apple (IpadOS o MacOS):
   - Opzione 1 (IpadOS): 
        - Avere Swift Playgrounds installato,
        - Aprire la cartella (/5_Applicativo/Nebula), 
        - Avviare l'applicativo
   - Opzione 2 (MacOS): 
        - Utilizzare XCode,
        - Aprire la cartella (/5_Applicativo/Nebula),
        - Aprire il file Nebula.swiftpm,
        - Avviare l'applicativo

IN CASO DI ERRORE NELL'OPZIONE 2:
- Utilizzare Swift Playgrounds,
- Aprire la cartella (/5_Applicativo/Nebula),
- Avviare l'applicativo
